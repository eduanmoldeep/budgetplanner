# Budget Planner

A Claude Code skill for simple pocket money planning: log income and spending, see your balance, and get a safe daily/weekly spend.

## Install

Project-local: use this repo as your working directory (the skill is in `.claude/skills/pocket-money-planner`).

Global: `cp -r .claude/skills/pocket-money-planner ~/.claude/skills/`

## Use

Ask Claude things like:

- "Set up my pocket money, I get 100 a month and want to save 60 for headphones"
- "I spent 4.50 on lunch"
- "How much can I spend per week?"

Data is stored in `pocket-money.csv` in your working directory.
